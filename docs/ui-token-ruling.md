# Token ruling: MASTER.md vs. the shipped palette

`design-system/subscription-monitor/MASTER.md` was generated by `uiux_design_system`
and classified this product as **Subscription Box Service / Funnel / Vibrant & Block-based**.

That classification does not describe this app. Subscription Monitor is a dense,
dark-first data dashboard for API usage and spend, shipped as a desktop Electron app.
Applying MASTER's generated artefacts literally would have:

- replaced the indigo/violet brand with magenta `#D946EF` and orange `#EA580C`;
- set Playfair Display as the body font (it is not loaded, and the UI is Inter-only);
- pushed body copy to 16px in a 1024px-min-width desktop shell where 14px is the
  established density;
- reintroduced contrast failures: white on `#D946EF` is 3.6:1 and text on
  `#EA580C` is 3.0:1, both below the AA floor this change set is fixing.

## What was adopted from MASTER

- **Token naming and scale structure**: `--space-*` (`xs`…`3xl`, aliased onto a 4px
  grid), `--shadow-{sm,md,lg,xl}`, `--radius-*`, and the semantic colour *roles*
  (`--color-*` equivalents expressed as `--accent`, `--on-accent`, `--danger`,
  `--on-danger`, `--muted`, `--border`).
- **The pre-delivery checklist**: no glyph icons in new markup, visible focus states,
  `prefers-reduced-motion`, `forced-colors` fallback, responsive at 375/768/1280,
  no horizontal scroll, no content under the fixed FAB.

## What was rejected, and why

The generated palette and typography. Brand colour, dark surface ramp and Inter are
the product's existing design language; changing them is a design decision for the
product owner, not a token-cleanup task. Every value that MASTER would have supplied
is instead expressed as a token in `public/styles.css`, so adopting a different
palette later is a change to the `:root` block only.

## Consequence for reviewers

`public/styles.css` defines every colour, space, radius, type, shadow and motion
value in one place. No literal colour, spacing, radius or font-size value appears in
the rule bodies. Layout constants that are structural rather than stylistic
(container `max-width`, `minmax()` column floors, control `max-width`, media-query
breakpoints, the 1px `sr-only` clip) remain literal by design.
